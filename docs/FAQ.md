# FAQ 自助查询功能方案

## 1. 功能目标

FAQ 自助查询用于帮助潜在客户、已合作客户和内部销售 / 实施同事快速获取常见问题答案，减少重复沟通，提升 BeeFintech Service Hub 的平台化服务感。

本功能属于第一阶段 P1 优先能力，目标是在不引入数据库的前提下，提供一个可演示、可维护、可扩展的静态 FAQ 页面。

## 2. 用户场景

- 潜在客户希望先了解产品接入方式、合作流程和数据安全边界，再决定是否预约演示。
- 已合作客户希望快速查看实施准备项、培训方式和售后支持说明。
- 销售 / 商务同事希望在演示沟通时快速定位问题答案，减少口头反复解释。
- 实施 / 交付同事希望统一常见答复口径，降低跨团队沟通成本。

## 3. 页面目标

- 让用户进入页面后能快速理解 FAQ 覆盖范围。
- 支持按分类筛选问题。
- 支持关键词搜索问题和答案。
- 支持折叠展开单个问题答案。
- 在无结果时提供清晰的空状态反馈和恢复建议。

## 4. 路由与文件范围

- 页面路由：`/faq`
- 方案文档：`docs/FAQ.md`
- 页面文件：`src/app/faq/page.tsx`
- 数据文件：`src/data/faq.ts`

如后续交互变复杂，可进一步拆分到 `src/components/faq/`。

## 5. 数据结构设计

第一阶段使用 TypeScript 常量维护 FAQ 数据，不引入数据库或 CMS。

建议结构：

```ts
type FaqCategory =
  | "all"
  | "integration"
  | "partnership"
  | "security"
  | "delivery"
  | "support";

type FaqItem = {
  id: string;
  question: string;
  answer: string;
  category: Exclude<FaqCategory, "all">;
  audience: string;
  keywords: string[];
};
```

说明：

- `id` 用于折叠项展开状态和后续锚点扩展。
- `keywords` 用于增强本地搜索命中率。
- `audience` 用于补充问题适用对象，增强扫读体验。

## 6. 分类设计

第一版 FAQ 使用以下分类：

- 全部问题
- 产品接入
- 保司合作
- 数据安全
- 实施交付
- 售后支持

分类需与 `docs/SPEC.md` 中描述保持一致，便于后续团队继续扩展内容。

## 7. 页面结构

### 7.1 顶部说明区

- 页面标题：`FAQ 自助查询`
- 简短说明：突出“接入、合作、安全、交付、售后”五类问题覆盖范围
- 快捷入口按钮：返回首页、预约演示

### 7.2 搜索与筛选区

- 关键词输入框
- 分类筛选按钮组
- 当前命中结果数提示

### 7.3 FAQ 列表区

- 问题卡片列表
- 单条问题支持展开 / 收起
- 展开后展示答案、适用对象、关键词标签

### 7.4 空状态区

- 当搜索无结果时，提示用户调整关键词或切换分类
- 提供一键返回“全部问题”的操作

## 8. 交互流程

### 8.1 搜索

- 用户输入关键词后，页面实时过滤结果
- 搜索范围包括：问题标题、答案正文、关键词标签、适用对象

### 8.2 分类筛选

- 用户点击某个分类后，只显示对应分类的问题
- 搜索和分类筛选可叠加使用

### 8.3 展开与收起

- 默认仅展开首条问题，降低初次进入的空白感
- 用户点击问题卡片后切换展开状态
- 第一版允许同时只展开一个问题，保持页面整洁

## 9. 异常与空状态

- 无搜索结果时显示“未找到匹配问题”的提示
- 空状态下提供“查看全部问题”按钮
- 第一版为静态数据页面，不涉及接口异常状态

## 10. 文案原则

- 中文界面优先
- 面向保险公司、经纪渠道、TPA、健康管理机构及内部交付同事
- 用词专业、克制、可信
- 未接入真实能力的内容使用“可支持”“通常会”“第一阶段以示例流程为主”等表述

## 11. 实施步骤

1. 新增 FAQ 功能方案文档，作为后续实现依据。
2. 在 `src/data/faq.ts` 中沉淀分类和问题数据。
3. 新增 `/faq` 页面，完成搜索、分类筛选、折叠展开和空状态。
4. 调整首页 FAQ 入口，使其直达新页面。
5. 运行 `npm run lint` 和 `npm run build` 验证。

## 12. 验收标准

- 存在独立 FAQ 页面路由 `/faq`
- 支持关键词搜索
- 支持分类筛选
- 支持问题答案展开 / 收起
- 无结果时有明确空状态提示
- 页面在桌面端和移动端均可正常浏览
- 首页存在进入 FAQ 页面入口
- `npm run lint` 通过
- `npm run build` 通过
